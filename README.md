# FLStudioTime 🎵⏱️

An international, lightweight, and free software to instantly calculate the total accumulated production time across all your FL Studio projects (`.flp`).

*Un logiciel international, léger et gratuit pour calculer instantanément le temps total cumulé passé sur l'ensemble de vos projets FL Studio (`.flp`).*

---

## 🌍 Multilingual Interface / Interface Multilingue / Interfaz Multilingüe
The software includes a built-in language selector at startup. No need for multiple versions, select your preferred language in 1 click:
- **English** 🇬🇧
- **Français** 🇫🇷
- **Español** 🇪🇸

---

## 🛠️ Features / Fonctionnalités
- **Deep Scan:** Automatically scans an entire folder and all its subfolders.
- **Smart Filtering:** Intelligently ignores "Backup" folders so automatic saves do not distort your final statistics.
- **Anti-Crash Safety:** If a project file is corrupted or unreadable, the software skips it and moves to the next one instead of crashing.
- **High Performance:** Capable of scanning hundreds of projects in just a few seconds.

> The user interface was intentionally left with a **standard/native Windows look** (Tkinter). This choice guarantees absolute stability and ensures the software runs flawlessly on 100% of Windows machines without any compatibility bugs or heavy external visual dependencies.

> *L'interface utilisateur a été volontairement laissée avec un **look standard/natif Windows** (Tkinter). Ce choix garantit une stabilité absolue et assure que le logiciel tourne parfaitement sur 100% des machines Windows, sans aucun bug de compatibilité ni dépendance visuelle externe lourde.*

---

## 🚀 How to use / Comment l'utiliser ?
1. Download the `FLStudioTime.exe` file.
2. Double-click to open it.
3. Choose your language (**FR / EN / ES**).
4. Click the green button, select your .flp folder (deepscan an entire folder and all its subfolders) and discover your total production time!


---

## ⚠️ Security Note / Note de sécurité (Windows SmartScreen)
When launching the software for the first time, Windows will probably display a blue security warning (*"Windows protected your PC"*). 
This is a **normal false positive**: the software is free, artisanal, and open-source, meaning it does not have an expensive official digital signature from Microsoft. 
To open it safely, simply click on **"More info"** and then **"Run anyway"**.
